# Shared scripts

Reviewed, reusable scripts. Everything here arrives by pull request.

| Folder | Contents |
| --- | --- |
| `tcl/` | Layout and tool automation in Tcl |
| `dv/` | Regression, log triage and testbench helpers |
| `integration/` | Top-level generators and connectivity checkers |

Create the folder with your first script. Each script needs a header comment
with its purpose, usage line and the tool and version it was tested on, and
must not contain PDK data, licence paths or project-specific net names.
